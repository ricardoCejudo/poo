## Descripcion

Se introduce el concepto de clases abstractas usando el modulo `abc` de Python. La clase `Animal` es abstracta y define el metodo `hablar()` como abstracto, lo que obliga a que cada clase hija lo implemente. No se puede crear un objeto directamente de `Animal`.

## Conceptos que se practican

- Clases abstractas con `ABC`
- Metodos abstractos con `@abstractmethod`
- Por que no se puede instanciar una clase abstracta
- Diferencia entre clase abstracta y clase normal
