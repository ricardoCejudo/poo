## Descripcion de la materia

Programacion Orientada a Objetos (POO) es una materia donde se aprende a estructurar programas usando clases y objetos. Los temas principales son encapsulamiento, herencia, polimorfismo y abstraccion. En este curso se usa Python como lenguaje de programacion.
