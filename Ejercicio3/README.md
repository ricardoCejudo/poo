## Descripcion

Se crea una clase padre `Animal` con atributos nombre y edad, y un metodo `hablar()` generico. Las clases hijas `Perro` y `Gato` heredan de Animal y sobreescriben el metodo hablar con su propio sonido.

## Conceptos que se practican

- Herencia simple
- Sobreescritura de metodos (override)
- Uso de `super()`
- Importar clases desde otros archivos

## Archivos

- `Animal.py` — clase padre
- `Perro.py` — clase hija
- `Gato.py` — clase hija
- `main.py` — creacion de objetos y prueba

## Como correr

```bash
python main.py
```
