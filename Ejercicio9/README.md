## Descripcion

Se aprende a trabajar con archivos de texto en Python. Se crea un archivo, se le agrega contenido con un bucle y se calcula su tamaño en KB y MB usando el modulo `os`.

## Conceptos que se practican

- Abrir archivos con `open()` en modo escritura (`w`) y append (`a`)
- Escribir en archivos con `write()`
- Cerrar archivos con `close()`
- Obtener el tamaño de un archivo con `os.path.getsize()`

## Archivos

- `Archivos.py` — crea el archivo `test.txt` y escribe contenido inicial
- `addy.py` — abre el archivo en modo append y agrega 50000 caracteres
- `filesize.py` — calcula y muestra el tamaño del archivo en KB y MB
