## Descripcion

Ejercicio completo de manejo de errores en Python dividido en 5 partes. Se aprende a usar `try`, `except`, `else` y `finally` para controlar errores comunes y tambien a crear excepciones personalizadas con `raise`.

## Partes del ejercicio

1. **Division segura** — captura `ZeroDivisionError` y `ValueError`
2. **Acceso a listas** — captura `IndexError` y `ValueError`
3. **Validacion con bucle** — funcion que repite hasta recibir un entero valido
4. **Lectura de archivos** — captura `FileNotFoundError` y `PermissionError`
5. **Excepciones personalizadas** — clases `EdadInvalidaError` y `SaldoInsuficienteError`

## Conceptos que se practican

- Bloque `try / except / else / finally`
- Captura de multiples excepciones
- Crear clases de excepcion propias
- Uso de `raise` para lanzar errores manualmente

## Archivos

- `excepciones.py` — las 5 partes en un solo archivo

## Como correr

```bash
python excepciones.py
```
