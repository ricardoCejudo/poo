## Descripcion

Este ejercicio es una introduccion a las clases en Python. Se crea la clase `Estudiante` con atributos basicos como nombre, edad y carrera. Tambien se usa una lista para guardar calificaciones y se calcula el promedio.

## Conceptos que se practican

- Constructor `__init__`
- Atributos de instancia
- Metodos getter y setter
- Listas dentro de una clase
- Creacion de objetos (instancias)
