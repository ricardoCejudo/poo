## Descripcion

Dos clases independientes en un mismo ejercicio. `CuentaBancaria` permite depositar, retirar y consultar saldo. `MascotaVirtual` tiene un nivel de felicidad que sube al alimentar o jugar con la mascota.

## Conceptos que se practican

- Encapsulamiento
- Validaciones dentro de metodos (fondos insuficientes, limites de felicidad)
- Metodos que modifican el estado del objeto

## Archivos

- `CuentaBancaria.py` — clase para manejar una cuenta bancaria
- `MascotaVirtual.py` — clase para simular una mascota virtual
